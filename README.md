# Hospital Лабораторная работа 1
## Описание проекта
**Hospital** - Проект иметирует основные сущности поликлиники, генерации тестовых данных и тесты для проверки

## Реализованные штуки

**Hospital.Models** - Модель поликлиники
**Patient** - Пациент, его ФИО, номер паспорта, пол, дата рождения, адресс, группа крови, резус фактор и номер телефона
**Doctor** - Врач, его ФИО, номер паспорта, год рождения, специализация и опыт
**Appointment** - Обращения в больничку, дата, номер кабинета

## Тесты проверяют
1. Врачей со стажем от 10 лет
2. Пациентов записанных к указаному врачу
3. Количестве повторных приемов за последний месяц
4. Пациентов старше 30 лет, записынные к нескольким врачам
5. Приемах за текущий месяц, проходящих в выбранном кабинете
